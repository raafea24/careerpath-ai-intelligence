# CareerPath AI Frontend

The frontend is a React 19 and Vite application for authenticated onboarding, CV upload, profile review, skill visualization, career recommendations, and dashboard progress views.

Configuration is supplied through `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`. See the repository-level `README.md` and `.env.example` for complete setup and architecture notes.
